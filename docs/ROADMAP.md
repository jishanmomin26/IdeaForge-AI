# IdeaForge AI — Design System

## 1. Overview

The IdeaForge AI design system defines the visual language, colors, typography, spacing, components, and interaction patterns used throughout the application.

The goal is to create a modern AI/SaaS interface that feels:

- Premium
- Innovative
- Clean
- Professional
- Futuristic
- Entrepreneurial
- Easy to use

The design should remain appropriate for a college mini-project and should not become unnecessarily complex.

---

# 2. Design Inspiration

The visual direction can take general inspiration from modern products such as:

- Google Gemini
- Vercel
- Linear
- Notion
- Framer
- Stripe

Important:

IdeaForge AI must maintain its own visual identity.

Do not directly copy layouts, branding, icons, or interfaces from these products.

---

# 3. Theme

## Color Mode

Dark Mode only.

The application should maintain a consistent dark interface throughout all pages.
